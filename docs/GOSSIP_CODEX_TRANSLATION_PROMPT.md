# Codex prompt: translate one private Gossip batch to Ukrainian

Run this workflow **only when the user explicitly requests local model
translation and accepts the model's normal usage/costs**.

You are assisting a human World of Warcraft: Forever Ukrainian localization
reviewer. The project is `spoken-ukrainian`, and the relevant data files
are generated by `tools/gossip_translation_review.py queue`.

## Task

Work on exactly one private file, for example:
`build/gossip-batches/batch-0001.json`.

Read the file. Its `entries` are English source text grouped by exact
English normalization. The `occurrence_count` tells you how many NPC
contexts share the same phrase. Translate **only** the value of
`entries[*].ukrainian_text` into natural Ukrainian.

Preserve ALL other fields, objects, ordering and values byte-for-byte as
JSON values, especially:
- `schema_version`, `spoken_revision`, `classicua_revision`
- `group_id`, `english_sha256`, `context_sha256`
- `english_original`, `occurrence_count`.

Never synthesize missing records or IDs; never mark any review as approved,
imported or release-ready. Do not change code, Git history, config or
source repositories. Do not delete previously translated batch content.

## Translation quality and safety

- Translate into idiomatic **Ukrainian**, not Russian; do not consult Russian
  localization, Russian-linked websites, or Russian translation files.
- Preserve the meaning, intent, register and faction character of the NPC.
  For Warcraft proper nouns, use established Ukrainian conventions when
  known and mark uncertain names for the human reviewer (outside the batch).
- Keep game variables and control tokens functionally unchanged:
  `$N`, `$n`, `<name>`, `<class>`, `<race>`, bracketed markup,
  `{...}`, formatting, line breaks, punctuation that controls branching,
  WoW color codes, and embedded escape sequences.
- A single Ukrainian phrase will apply to ALL listed NPC contexts. Where
  English is ambiguous about speaker/player sex, **prefer wording safe for
  any gender**. If that is not feasible, leave `ukrainian_text` blank for
  human handling and report that group separately.
- Avoid hallucinating context or claiming the translated line already
  appears in ClassicUA. Never silently alter NPC or Quest identifiers.
- Render Unicode as UTF-8 (not escaped ASCII sequences unless needed).
  Carefully use Ukrainian letters `і`, `ї`, `є`, `ґ` where appropriate.

## Output / validation

Save the **same** JSON file with original metadata and translated
`ukrainian_text` fields. Do not create an API integration, public artifact,
or Git commit. Report only aggregate counts (translated, skipped,
ambiguous) and groups needing reviewer attention.

Before marking this batch complete, validate JSON syntax and recheck that
all metadata and source English strings are unchanged. Do not auto-run
`propose`, `review` or `import-approved`: those are explicit owner
actions. For a partially filled batch, first remove or separately queue
blank entries before using the `propose` CLI because it validates all
submitted entries.

Remember: LLM output is always **pending**. Approval demands five human
attestations, including rights and correctness for every NPC context.
