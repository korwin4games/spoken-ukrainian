# Інтеграція текстових модулів Spoken 3.10.1

**Issue #38 / PR #39.** Quest і Gossip — окремі текстові аддони, які не потребують українського озвучення. Пакети призначені для приватного тестування. **Перевірка у WoW: Forever ще не виконана.**

## Перевірені джерела та API

- Офіційний Spoken: тег **spoken/v3.10.1**, коміт `db5669b0a39815dd38568f0e871f4ced82bc9229`.
- Поточні `sources.lock.json` і Stage 3 pin оновлено до 3.10.1. Всі 13 файлів Stage 3, включно з корпусом Quest/Gossip та aliases, мають **ті самі Git blob**, що й у 3.9.0. Історичні Stage 1/2B тести залишаються прив’язаними до 3.9.0 окремим архівним manifest.
- Спільний `Spoken_Ukrainian` реєструє тексти публічним `Spoken:RegisterText("ukUA", "quests", ...)`, якщо метод існує.
- Формат ID: `q:ID:accept`, `q:ID:progress`, `q:ID:complete`; для окремих варіантів існують `:wN` та `:m/:f`. Gossip використовує канонічні `g:...`, відмінні від ключів ClassicUA NPC/hash.
- У **Compendium → Quests** передбачені accept і complete. Етап progress перевіряють у власному підтриманому контексті, а не як окремий розділ сторінки Compendium.

## Архітектура модулів

- `Spoken_Quest_UA`: український Text Pack для Compendium і штатні QuestFrame/Quest Journal, підтримка Shift та наявний локальний preview.
- `Spoken_Gossip_UA`: Text Pack і переклади штатних Gossip-вікон, перевірені за NPC/англійським хешем. Має **власний Noto Sans і ліцензію**, навіть якщо Quest-модуль не встановлено.
- Кожен ZIP містить вибраний модуль і спільне ядро `Spoken_Ukrainian`. Озвучення не генерується. Офіційні `Spoken` та `Spoken_Quests` не змінюються.
- Quest/Gossip завантажуються як звичайні аддони, оскільки мають також native UI hooks. Це дозволено офіційним протоколом Text Packs; `LoadOnDemand` рекомендований для суто текстових пакетів без native hooks.

## Чому деякі переклади не з’являться у Spoken

- Для приватного тестування **один допустимий переклад ClassicUA автоматично застосовуємо до всіх перевірених англійських варіантів одного Quest ID та етапу**. Загальний `q:ID:event` працює для цих варіантів; `:wN` та `:m/:f` окремо не вигадуємо. Людське схвалення не потрібне для статусу «Готовий до імпорту». Непідтверджені оригінали, змінений контекст, неправильна фракція, явне відхилення та конфлікт кількох різних українських текстів блокують імпорт. Для публічного релізу схвалення залишиться окремою умовою.
- Якщо канонічний `g:...` використовують кілька NPC, переклад експортується тільки за наявності перевірених сумісних рішень **для всіх** контекстів цього ID. Конфлікти, відсутні вибори, об’єкти поза областю редактора чи різні англійські тексти блокують глобальний Text Pack. Штатний NPC-specific Gossip при цьому працює незалежно.
- Плейсхолдери `{ім'я}`, `{клас}`, `{раса}` і підтримані форми статі перетворюються у `$N`, `$C`, `$R`, `$Gmale:female;`. Непідтримувані відмінки й пошкоджені шаблони **не експортуються**, щоб не показувати сирі коди.
- Якщо назви квесту відрізняються між фракціями, загальний ID назви пропускається. Відсутність перекладу дає звичайний англійський fallback.
- Локальний вибір або машинний імпорт не дорівнює людському схваленню.

## Створення ZIP та інсталяція

Використовуйте чисті checkout джерел **саме на комітах із** `sources.lock.json`:

```bash
uv sync --locked
uv run --locked python tools/build_ukrainian.py --module Spoken_Quest_UA --classicua ../ClassicUA --spoken ../spoken-wow
uv run --locked python tools/build_ukrainian.py --module Spoken_Gossip_UA --classicua ../ClassicUA --spoken ../spoken-wow
```

У Translation Manager оберіть Quest або Gossip. **«Створити модуль»** збирає лише вибраний ZIP. **«Інсталювати»** спочатку збирає ZIP, перевіряє SHA-256 і встановлює його до `<WoW path>/_forever_/Interface/AddOns`, створюючи backup змінюваних папок. Шлях WoW зберігається під час перемикання модулів.

Для перевірки інсталятора з CLI:

```bash
uv run --locked python tools/install_addon.py --addons "/path/to/World of Warcraft/_forever_/Interface/AddOns" --archive dist/Spoken_Gossip_UA_Local_Test.zip --dry-run
```

Перед змінами **закрийте WoW**, збережіть копію `Interface/AddOns` і `WTF` (SavedVariables). Резервні копії, які створює інсталятор, лежать у `Interface/AddOns/.spoken-ukrainian-backups/`. Для ручного відкату видаліть лише нові українські папки й поверніть попередні версії з відповідного backup. Офіційні аддони не змінюйте.

## Ігрове тестування — ще не виконано

Причину квадратиків на правій сторінці завдання та команду для перевірки
описано в [розборі шрифтів Компендіуму](SPOKEN_3101_COMPENDIUM_FONT.uk.md).

1. Встановіть офіційні `Spoken` та `Spoken_Quests` версії 3.10.1. Увімкніть **тільки Quest** і перевірте Spoken Settings → Language → **Text Language → Ukrainian**. Виконайте `/reload`.
2. Перевірте кирилицю **і ї є ґ І Ї Є Ґ**, українські назви квестів, accept/complete в Compendium та англійський fallback.
3. Перевірте QuestFrame, журнал, Shift для оригіналу, ім’я/клас/расу/стать та перенесення рядків.
4. Вимкніть Quest, увімкніть **тільки Gossip**. Перевірте вибір української мови, всі літери, репліки NPC та відсутність чужого перекладу для спільного `g:...`.
5. Увімкніть обидва модулі без українського voice pack. Перевірте їхню незалежну роботу та відсутність фіктивного аудіо.
6. Повторіть із ClassicUA та без нього. Перевірте пріоритет перекладів, fallback і Lua-помилки.
7. Зі старішим Spoken без `RegisterText` перевірте відсутність Lua-помилок та роботу native перекладу, але **не очікуйте** Compendium Text Pack.
