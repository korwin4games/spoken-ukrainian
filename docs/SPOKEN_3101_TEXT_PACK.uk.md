# Інтеграція Text Pack API Spoken 3.10.1 (ЧЕРНЕТКА)

**Обсяг:** issue #38 / PR #39. Українські текстові модулі незалежні від озвучення. Поки що це приватні тестові збірки.

## API та версія

Офіційний тег \`spoken/v3.10.1\` відповідає коміту \`db5669b0a39815dd38568f0e871f4ced82bc9229\`. В upstream підтверджено контракт \`Spoken:RegisterText("ukUA", "quests", ...)\`, ключі назв квестів за Quest ID та канонічні \`q:...\` / \`g:...\` для реплік. Compendium використовує цей API, коли у налаштуваннях Spoken вибрано **Text Language → Ukrainian** та виконано \`/reload\`.

**Увага:** \`sources.lock.json\` проєкту й досі закріплює Spoken **3.9.0**. Без повторної перевірки корпусу, хешів джерел та канонічних ідентифікаторів не можна називати сумісність із 3.10.1 завершеною.

## Модулі

- \`Spoken_Ukrainian\` — спільна реєстрація через публічний API з перевіркою його наявності.
- \`Spoken_Quest_UA\` — назви й тексти квестів для Compendium, а також наявні переклади стандартних вікон і Shift.
- \`Spoken_Gossip_UA\` — NPC-діалоги та канонічні текстові записи \`g:...\`, без злиття різних перекладів для одного ID.

Текстові модулі не підмінюють голосові й не створюють фіктивних аудіофайлів. Непідтримувані граматичні відмінки, неоднозначні ID та конфліктні переклади пропускаються з англійським fallback.

## Перевірка у WoW: Forever (ще не виконана)

1. Зробіть резервну копію поточних аддонів і налаштувань. Не замінюйте офіційний Spoken файлами української тестової збірки.
2. Перевірте версії офіційних \`Spoken\` і \`Spoken_Quests\` — **3.10.1**.
3. Для генератора використовуйте **чисті checkout саме на ревізіях із \`sources.lock.json\`**, доки не завершена міграція pin до 3.10.1.
4. Зберіть два модулі окремо:

   \`\`\`bash
   uv run --locked python tools/build_ukrainian.py --module Spoken_Quest_UA --classicua ../ClassicUA --spoken ../spoken-wow
   uv run --locked python tools/build_ukrainian.py --module Spoken_Gossip_UA --classicua ../ClassicUA --spoken ../spoken-wow
   \`\`\`

5. Інсталюйте тестовий модуль. Відкрийте налаштування Spoken → Language → **Text Language → Ukrainian**, виконайте \`/reload\`.
6. Перевірте назви, accept/progress/complete в Compendium й англійський fallback без перекладу.
7. Перевірте QuestFrame, журнал, Gossip і Shift; підстановки імені, класу, раси та статі, абзаци й усі українські літери.
8. Вимкніть Quest і перевірте Gossip окремо, потім навпаки. Повторіть із ClassicUA, щоб перевірити пріоритети.
9. Підтвердьте відсутність фіктивного озвучення, непередбачених змін Approval та конфліктів ID.
