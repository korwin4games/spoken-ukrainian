# Менеджер перекладів Quest

У модулі `Spoken_Quest_UA` залишено три випадки:

1. **Немає перекладу.** Відкрийте квест, введіть український текст і натисніть **Зберегти переклад**. Кнопка **Скопіювати запит для Codex** копіює англійський текст і вимоги до підстановок; Codex запускається окремо, результат вставляється в це поле. Це не автоматичний виклик моделі.
2. **Один оригінал, декілька перекладів.** Порівняйте варіанти у списку **Оберіть переклад** і натисніть **Зберегти вибір**. Це збереже вибір у SQLite, але **не** оновлюватиме ZIP.
3. **Два оригінали, один переклад.** Якщо визначено Quest ID/етап і відповідні англійські контексти, локальний Quest ZIP автоматично використовує той самий переклад для обох. Збіг змінних, стилю чи форматування більше не є умовою імпорту.

У Quest UI немає рецензентів, галочок, додаткових діалогів підтвердження чи валідаторів граматики, змісту, підстановок і форматування. Можна зберігати текст з `$N`, `$B` чи власними конструкціями; за точність відповідає автор перекладу. `$N` і `$B` відображаються у Quest як ім’я персонажа та новий рядок. Залишаються лише технічні обмеження (непорожній рядок, розмір, NUL, зв’язок із Quest ID/етапом та перевірка зібраного ZIP). Історичні записи SQLite залишаються в базі для безпеки. Нові локальні вибори зберігаються в `quest_simple_choices` з відбитком поточного контексту. Це **локальний тестовий ZIP**, не публічне схвалення текстів.

## Запуск

```bash
uv sync --locked
uv run --locked python tools/translation_db.py status
uv run --locked python tools/translation_db.py backup
uv run --locked python tools/review_ui_server.py --classicua ../ClassicUA --spoken ../spoken-wow
```

Відкрийте http://127.0.0.1:8765/ та виберіть `Spoken_Quest_UA`. Після додавання перекладу або вибору кандидата статус стає **Готовий до імпорту**; ZIP не змінюється. Одна глобальна кнопка **Імпортувати все (N)** імпортує всі готові переклади у Quest ZIP зі збереженням уже імпортованих. Статус **У ZIP** з'являється лише після успішної збірки і перевірки архіву. Якщо змінився оригінал або контекст, локальний вибір більше не підставляється без повторного вибору.

Деталі встановлення: [QUEST_LOCAL_TEST_BUILD.md](QUEST_LOCAL_TEST_BUILD.md).
