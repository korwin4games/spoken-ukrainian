# Менеджер перекладів

1. Підготуйте чисті ClassicUA та Spoken за [посібником CLI](CLI.uk.md). Запустіть менеджер з кореня проєкту.

   ```bash
   uv sync --locked
   uv run --locked python tools/review_ui_server.py --classicua ../ClassicUA --spoken ../spoken-wow
   ```

2. Відкрийте [127.0.0.1:8765](http://127.0.0.1:8765/) і виберіть `Spoken_Quest_UA` або `Spoken_Gossip_UA`. Поточний ZIP, SHA-256, лічильники, пошук і фільтри стосуються вибраного модуля. Quest рахується за ID та етапом, Gossip за NPC і контекстом оригіналу. Спільна репліка в ZIP може покривати кілька рядків.
3. Відкрийте запис, щоб звірити оригінал, контекст, джерела й статуси. **У ZIP** з’являється після перевірки контрольної суми та фактичного вмісту локальної збірки. **Лише в базі** означає збережений імпорт без включення до поточного ZIP.
4. Для кандидата ClassicUA без зіставлення розкрийте **Перевірка зіставлення Stage 3**. Виберіть точну пару та контекст. Перший рецензент звіряє наведені посилання із закріпленими файлами й перевіряє етап, фракцію, NPC, голос, стать і текст. Другий незалежно повторює перевірку. Введіть два різні ідентифікатори, окремо позначте підтвердження й натисніть **Підтвердити зіставлення**.
5. Виберіть допущеного кандидата ClassicUA, введіть ім’я й натисніть **Додати кандидат до журналу**. Потрібні чинне зіставлення Stage 3, перевірені дані джерела й дозвіл на локальне зберігання. Для власного Quest-тексту введіть текст у полі чернетки й натисніть **Зберегти чернетку**. Для цього достатньо перевіреного оригіналу для кожного контексту. У Gossip чернетка належить групі перевірених оригіналів. Реєстрація, чернетка та зіставлення зберігаються окремо від збірки. Зовнішні кандидати додаються через `source_revision_review.py` за [посібником CLI](CLI.uk.md).
6. Для конфлікту українських кандидатів виберіть доступну версію. Стан зіставлення, стан перевірки та фактичне включення до ZIP відображаються окремо. Біля кожного варіанта є підказка про відсутнє зіставлення, застарілий доказ, права або формат. Звірте оригінал і джерело, заповніть ім’я та всі п’ять перевірок. Натисніть **Підтвердити переклад**. Рішення застосовується, коли відбиток вибраного тексту перевірено в новому ZIP. Чинне суперечливе ручне схвалення потребує окремого перегляду в CLI.
7. Натисніть **Попередній перегляд** для ізольованої збірки або **Переімпортувати Quest** чи **Переімпортувати Gossip** для публікації локального ZIP. Підтверджене скидання замінює лише тестові рішення, імпорти, пам’ять та оцінки вибраного модуля. Знімки провайдерів та історія збірок зберігаються.

## Приклад перевірки Quest

1. Відкрийте вигаданий запис `q:42:accept` із двома перекладами, «Вітаю!» і «Доброго дня!». Порівняйте тексти й виберіть потрібний у полі **Кандидат перекладу**. Реєстрація і збереження чернетки залишають версію на перевірці.
2. Якщо для цієї події є два англійські оригінали, звірте обидва тексти, ID, версії, відбитки та контексти, зокрема NPC, фракцію і голос. Позначте, що вибраний текст підходить для всіх наведених оригіналів і контекстів. Окремо підтвердьте текст, граматику й формат, походження й використання ШІ та права.
3. Натисніть **Підтвердити переклад**. Менеджер збере `Spoken_Quest_UA`, перечитає текст із `Spoken_Quest_UA/Translations.lua` в ZIP і звірить SHA-256. Після успішного застосування біля вибраного тексту з’явиться **У ZIP**, а для спільного рішення буде вказано кількість покритих оригіналів. У файлі є один запис `[42].accept`.
4. Після зміни оригіналу, контексту або закріпленої версії перевірте весь актуальний набір знову. Різні чинні схвалення блокують збірку цього запису. Виберіть попередню версію й натисніть **Відкликати схвалення Quest**, якщо її схвалили в менеджері. Для рішень попереднього журналу або активного зовнішнього джерела використовуйте відповідні команди CLI. Відкликання зберігає історію. ZIP змінюється під час наступної успішної збірки.
5. Встановіть новий локальний ZIP і, вимкнувши ClassicUA, перевірте в WoW: Forever `і ї є ґ І Ї Є Ґ` у заголовках, описі, цілях, тексті прогресу та завершення NPC, а також в опційному вікні попереднього перегляду. Прийміть перекладений квест. У журналі перевірте заголовок у списку і в деталях, опис і загальні цілі. Перейдіть до іншого квесту, прокрутіть список, оновіть цілі, закрийте й відкрийте журнал, скасуйте або завершіть квест. Утримуйте Shift на кожній нативній поверхні й звірте точний англійський текст і початковий шрифт. Окремі лічильники цілей та нагороди залишаються мовою клієнта.

## Міграція та діагностика

База SQLite зберігає чинні рішення й історію старого спільного ZIP. Міграція 8 додає історію чернеток, схвалень і відкликань для Quest. До першої окремої збірки менеджер покаже, що перевіреного ZIP для модуля ще немає. Збій збірки зберігає попередній успішний стан. Якщо інший процес змінив базу, оновіть сторінку й повторіть дію. Перевіряйте статуси джерел за [посібником CLI](CLI.uk.md). Порядок встановлення та ручні тести описані в [інструкції для WoW Forever](QUEST_LOCAL_TEST_BUILD.md).
