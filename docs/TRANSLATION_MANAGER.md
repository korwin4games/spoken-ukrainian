# Менеджер перекладів

1. Підготуйте чисті ClassicUA та Spoken за [посібником CLI](CLI.uk.md). Запустіть менеджер з кореня проєкту.

   ```bash
   uv sync --locked
   uv run --locked python tools/review_ui_server.py --classicua ../ClassicUA --spoken ../spoken-wow
   ```

2. Відкрийте [127.0.0.1:8765](http://127.0.0.1:8765/) і виберіть `Spoken_Quest_UA` або `Spoken_Gossip_UA`. Поточний ZIP, SHA-256, лічильники, пошук і фільтри стосуються вибраного модуля. Quest рахується за ID та етапом, Gossip за NPC і контекстом оригіналу. Спільна репліка в ZIP може покривати кілька рядків.
3. Відкрийте запис, щоб звірити оригінал, контекст, джерела й статуси. **У ZIP** з’являється після перевірки контрольної суми та фактичного вмісту локальної збірки. **Лише в базі** означає збережений імпорт без включення до поточного ZIP.
4. Якщо бракує зіставлення Quest, розкрийте **Перевірка зіставлення Stage 3**. Виберіть точну пару та контекст. Перший рецензент звіряє наведені посилання із закріпленими файлами й перевіряє етап, фракцію, NPC, голос, стать і текст. Другий незалежно повторює перевірку. Введіть два різні ідентифікатори, окремо позначте підтвердження й натисніть **Підтвердити зіставлення**. Форма передає перевірені посилання й факти, тому вручну складати JSON не потрібно. За відсутності однозначної пари потрібна окрема перевірка джерел. Якщо гра передає лише ID та етап, а Spoken має кілька різних оригіналів, запис залишиться поза ZIP.
5. Якщо кандидат ClassicUA пропонує **Додати кандидат до журналу**, виберіть його, введіть ім’я й збережіть. Потрібні чинне зіставлення Stage 3, перевірені дані джерела і дозвіл на локальне зберігання. Для власного тексту використайте **Зберегти чернетку**, коли доступна однозначна перевірена основа. У Gossip чернетка належить групі перевірених оригіналів. Реєстрація, чернетка та зіставлення зберігаються окремо від збірки. Записи, що потребують реєстрації зовнішнього джерела, можна додати через `source_revision_review.py` за [посібником CLI](CLI.uk.md).
6. Для конфлікту українських кандидатів виберіть доступну версію. Стан зіставлення, стан перевірки та фактичне включення до ZIP відображаються окремо. Біля кожного варіанта є підказка про відсутнє зіставлення, застарілий доказ, права або формат. Звірте оригінал і джерело, заповніть ім’я та всі п’ять перевірок. Натисніть **Підтвердити переклад**. Рішення застосовується, коли відбиток вибраного тексту перевірено в новому ZIP. Чинне суперечливе ручне схвалення потребує окремого перегляду в CLI.
7. Натисніть **Попередній перегляд** для ізольованої збірки або **Переімпортувати Quest** чи **Переімпортувати Gossip** для публікації локального ZIP. Підтверджене скидання замінює лише тестові рішення, імпорти, пам’ять та оцінки вибраного модуля. Знімки провайдерів та історія збірок зберігаються.

## Міграція та діагностика

База SQLite зберігає чинні рішення й історію старого спільного ZIP. До першої окремої збірки менеджер покаже, що перевіреного ZIP для модуля ще немає. Збій збірки зберігає попередній успішний стан. Якщо інший процес змінив базу, оновіть сторінку й повторіть дію. Перевіряйте статуси джерел за [посібником CLI](CLI.uk.md). Порядок встановлення та ручні тести описані в [інструкції для WoW Forever](QUEST_LOCAL_TEST_BUILD.md).
