# Менеджер перекладів Quest і Gossip

## Покриття перекладом — Quest і Gossip

Для кожного з двох модулів показано **«Покриття перекладом»** із відсотком та
кількістю покритих записів. Формула: **(Імпортовано + Готові до імпорту) /
Усі записи вибраного модуля × 100%**. Взаємно виключні категорії:
якщо запис має попередній ZIP, але готовий до нового імпорту, рахуємо його
**один раз** у «Готові до імпорту». Решта — «Проблемні». Лічильник охоплює
весь проіндексований модуль та **не змінюється через пошук, фільтрацію й
пагінацію**. Для порожнього модуля показуємо «—», а не 0%.

Quest — одиниця підрахунку **Quest ID + етап** (`accept`, `progress`,
`complete`); Gossip — **NPC + хеш оригінальної репліки**. Це потенційне
покриття для локального ZIP, а не гарантія показу перекладу в грі і не
кількість усіх квестів World of Warcraft. Перевіряйте реальний результат
у WoW: Forever після інсталяції.

## Автоімпорт Quest — правило для приватного тестування

Переклади Quest максимально спрощено: один допустимий переклад ClassicUA
для перевірених **Quest ID + етапу** автоматично застосовується до
**всіх англійських формулювань цього етапу**. Не потрібні людські
схвалення Mapping/Translation чи натискання «Зберегти». Статус
**«Готовий до імпорту»** присвоюємо, коли цей текст реально потрапить
у наступний ZIP. У Spoken Compendium використовуємо базовий
`q:ID:event` для різних варіантів без вигадування окремих `:wN`/статевих ID.

Різні українські переклади потребують вибору. Не змішуємо різні Quest ID,
етапи чи несумісні фракції; не імпортуємо неперевірені оригінали,
зіпсоване джерело, явно відхилені рішення чи текст поза дозволеною
політикою. Схвалення для публікації залишається окремим процесом.
Історія SQLite зберігається; безпечний автоімпорт призначений лише
для локального тесту в WoW: Forever. Для Gossip правила NPC/hash
залишаються незмінними.

## Сумісність збережених Quest-рішень після Spoken 3.10.1

Після оновлення Spoken з 3.9.0 на 3.10.1 локальні рішення для Quest можуть
мати старий fingerprint, оскільки він включає SHA коміту Spoken. Оригінальний
корпус, фракції й інші 13 файлів Stage 3 перевірено як байтово однакові.
Менеджер **лише читає** попередні вибори та людські схвалення як чинні, якщо
всі перевірені контексти, ID, англійські тексти, версія ClassicUA та інші поля
доказу збігаються; змінювати SQLite або повторно схвалювати переклади не треба.

Попередній Quest ZIP зі старим pin дозволено використовувати тільки як
джерело для **нового інкрементального ZIP**, якщо його SHA-256 та історія
імпорту збігаються. До нової збірки він не вважається встановленою версією
для 3.10.1. Новий ZIP міститиме актуальний Spoken Text Pack. Якщо джерело,
контекст чи SHA архіву відрізняються, імпорт блокується; старі рішення
залишаються в SQLite для перевірки. **Не видаляйте базу та не запускайте
`--reset-test-data` для виправлення статусів.**

Перевірте лічильники перед і після оновлення UI, тоді запустіть
**«Створити модуль»** і перевірте Compendium у WoW: Forever. Кількість
відновлених записів залежить від вашої локальної SQLite і не визначається
з GitHub CI.


Менеджер збирає приватні модулі `Spoken_Quest_UA` та `Spoken_Gossip_UA`. Кожен ZIP містить вибраний аддон і спільний `Spoken_Ukrainian`.

```bash
uv sync --locked
uv run --locked python tools/review_ui_server.py --classicua ../ClassicUA --spoken ../spoken-wow
```

1. Відкрийте локальний менеджер за адресою http://127.0.0.1:8765/ і виберіть модуль.
2. Відкрийте запис, прочитайте оригінал і контекст. **Один перевірений український кандидат ClassicUA одразу готовий до імпорту**, навіть за кількох англійських оригіналів. Якщо є кілька різних українських кандидатів, виберіть потрібний.
3. За потреби скопіюйте запит для Codex, запустіть Codex окремо та вставте результат.
4. **Зберегти** потрібно лише для власного тексту або вибору між різними кандидатами. Автоматично вибраний єдиний переклад не потребує збереження в SQLite й одразу має стан **Готовий до імпорту**.
5. Натисніть **Створити модуль**. Менеджер показує назву модуля, кількість імпортованих, готових і проблемних записів, шлях до ZIP і SHA-256. Quest додає готові зміни до перевіреного попереднього ZIP. Gossip збирає всі чинні локальні вибори, включно з раніше збереженими. Перший Gossip ZIP може містити порожню таблицю перекладів.
6. Закрийте гру. У спільному полі **WoW path** вкажіть корінь гри, наприклад `D:\Games\World of Warcraft`. Менеджер додає `_forever_/Interface/AddOns` і приймає кінцевий слеш. Поле зберігає значення під час зміни модуля.
7. Натисніть **Інсталювати**. Менеджер збирає вибраний модуль, перевіряє ZIP та контрольну суму, перевіряє залежності й резервує наявні папки. У результаті видно каталог та шлях до резервної копії. Після помилки збірки інсталяція не починається.

## Новий стан Gossip

Міграція SQLite v10 додає `gossip_simple_choices`. Попередні рішення залишаються в історії. Нові вибори використовують лише чинні закріплені джерела. Кандидати `whitespace_candidate` і `same_template` після окремої перевірки оригіналів, області NPC/!common, джерела та плейсхолдерів можуть бути вибрані автоматично. TTS, відмінність в одному слові, інший NPC та решта приблизних збігів доступні лише як докази для перегляду. Для локального перекладу ключем є NPC і хеш перевіреного оригіналу. Спільний кандидат ClassicUA після вибору записується для поточного NPC. У своєму тексті залишайте `$N`, `$C`, `$R`, `$B` і обидві гілки `$G`, якщо вони є в оригіналі.


### Статуси й ID Gossip

У списку Gossip дві окремі колонки: **npcID** (ID персонажа) та **ID** (32-бітний хеш англійської репліки, який використовує Gossip runtime). Наприклад, `gossip:68:107874079` означає `npcID=68`, `ID=107874079`. Це не ID квесту і не довільний номер рядка Spoken.

**Готовий до імпорту** означає збережений вибір або один однозначний, допустимий переклад ClassicUA для перевіреного контексту: точний хеш, безпечна нормалізація пробілів або перевірений збіг англійського шаблону. Його можна включити кнопкою **Створити модуль** без окремого збереження. Уже включений переклад зі збіжним хешем у перевіреному ZIP має статус **Імпортовано**. Різні варіанти перекладу, недійсний оригінал, змінений контекст та відсутність допустимого тексту залишаються проблемними й потребують дії користувача. Фільтр **Тип відповідності** в Gossip працює разом зі станом і пошуком у всій таблиці до пагінації. Повний тип доказу відображається також у деталях. `one_token_edit`, інший NPC та TTS не вибираються автоматично. Автоматичне зіставлення не означає людського схвалення перекладу; різні записи джерела з однаковим перекладом також залишаються неоднозначними.

## Ручна перевірка WoW Forever

1. Увімкніть основний український аддон і вибраний модуль. Перевірте офіційні залежності та вимкніть ClassicUA для перевірки українських вікон від цього проєкту.
2. Поговоріть з NPC, для якого зберегли переклад Gossip. Перевірте привітання і пункт діалогу. Утримуйте Shift для англійського оригіналу, потім відпустіть Shift.
3. Поговоріть з NPC без вибраного перекладу і перевірте англійський текст. Для репліки з параметрами перевірте ім’я, клас, расу, абзаци та обидві гілки статі на відповідних персонажах.
4. Повторіть з іншим модулем. Перевірте, що перший модуль та офіційні аддони присутні, а у QuestFrame працює Shift. Результат перевірки в реальному клієнті фіксується окремо.
