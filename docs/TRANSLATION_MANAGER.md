# Менеджер перекладів Quest

У модулі `Spoken_Quest_UA` залишено три випадки:

1. **Немає перекладу.** Відкрийте квест, введіть український текст і натисніть **Зберегти**. Кнопка **Скопіювати запит для Codex** копіює англійський текст і вимоги до підстановок; Codex запускається окремо, результат вставляється в це поле. Це не автоматичний виклик моделі.
2. **Один оригінал, декілька перекладів.** Виберіть потрібний у списку: текст з’явиться у редагованому полі. Залиште його без змін або відредагуйте, після чого натисніть **Зберегти**. Незмінений варіант зберігає джерело, редагований — власний переклад. Це змінює лише SQLite, **не** ZIP.
3. **Два оригінали, один переклад.** Якщо визначено Quest ID/етап і відповідні англійські контексти, локальний Quest ZIP автоматично використовує той самий переклад для обох. Збіг змінних, стилю чи форматування більше не є умовою імпорту.

У Quest UI немає рецензентів, галочок, додаткових діалогів підтвердження чи валідаторів граматики, змісту, підстановок і форматування. Можна зберігати текст з `$N`, `$B` чи власними конструкціями; за точність відповідає автор перекладу. `$N` і `$B` відображаються у Quest як ім’я персонажа та новий рядок. Залишаються лише технічні обмеження (непорожній рядок, розмір, NUL, зв’язок із Quest ID/етапом та перевірка зібраного ZIP). Історичні записи SQLite залишаються в базі для безпеки. Нові локальні вибори зберігаються в `quest_simple_choices` з відбитком поточного контексту. Це **локальний тестовий ZIP**, не публічне схвалення текстів.

## Запуск

```bash
uv sync --locked
uv run --locked python tools/translation_db.py status
uv run --locked python tools/translation_db.py backup
uv run --locked python tools/review_ui_server.py --classicua ../ClassicUA --spoken ../spoken-wow
```

Відкрийте http://127.0.0.1:8765/ та виберіть `Spoken_Quest_UA`. Після додавання перекладу або вибору кандидата статус стає **Готовий до імпорту**; ZIP не змінюється. Три лічильники й фільтри показують **Імпортовано**, **Готові до імпорту**, **Проблемні**. Кнопка **Створити модуль** формує інсталяційний архів `Spoken_Quest_UA_Local_Test.zip`: додає всі квести зі статусом **Готовий до імпорту** та зберігає квести, які вже містяться в попередньому перевіреному ZIP. Це не повторний імпорт усіх кандидатів. Вже імпортовані Quest ID/етапи переносяться з попереднього перевіреного ZIP без зміни тексту або джерела. Якщо готовий запис уже імпортований, його текст замінюється тільки для цього Quest ID/етапу.

Новий ZIP технічно створюється цілком, але до нього потрапляють лише раніше імпортовані та готові до імпорту тексти; інші кандидати не додаються автоматично. Після успішної збірки та перевірки SHA-256 статус змінюється на **У ZIP**. Якщо змінився оригінал або контекст, локальний вибір більше не підставляється без повторного вибору. Пошкоджений, змінений зовні або невідстежуваний попередній ZIP блокує інкрементальний імпорт, а не перезаписується тихо.

**Для чого SQLite та ZIP:** SQLite зберігає вибрані тексти, готовність до імпорту та історію. WoW не використовує SQLite напряму: переклади серіалізуються у `Spoken_Quest_UA/Translations.lua` і запаковуються в локальний інсталяційний ZIP. Після встановлення Lua-файли читає WoW; збереження в браузері саме по собі не оновлює встановлений аддон.

Деталі встановлення: [QUEST_LOCAL_TEST_BUILD.md](QUEST_LOCAL_TEST_BUILD.md).
