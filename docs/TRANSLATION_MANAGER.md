# Менеджер перекладів Quest

У модулі `Spoken_Quest_UA` залишено три випадки:

1. **Немає перекладу.** Відкрийте квест, введіть український текст і натисніть **Зберегти й застосувати**. Кнопка **Скопіювати запит для Codex** копіює англійський текст і вимоги до підстановок; Codex запускається окремо, результат вставляється в це поле. Це не автоматичний виклик моделі.
2. **Один оригінал, декілька перекладів.** Порівняйте варіанти у списку **Оберіть переклад** і натисніть **Використати переклад**. Менеджер збере лише Quest ZIP й перевірить вибраний текст у ZIP.
3. **Два оригінали, один переклад.** Якщо закріплені Quest ID/етап і змінні збігаються, локальний Quest ZIP автоматично використає той самий текст для обох англійських оригіналів.

Рецензентських імен, п'яти галочок та історичних журналів у Quest UI більше немає. Історичні записи SQLite залишаються в базі для безпеки. Нові локальні вибори зберігаються в `quest_simple_choices` з відбитком поточного контексту. Це **локальний тестовий ZIP**, не публічне схвалення текстів.

## Запуск

```bash
uv sync --locked
uv run --locked python tools/translation_db.py status
uv run --locked python tools/translation_db.py backup
uv run --locked python tools/review_ui_server.py --classicua ../ClassicUA --spoken ../spoken-wow
```

Відкрийте http://127.0.0.1:8765/ та виберіть `Spoken_Quest_UA`. Статус **У ZIP** з'являється лише після успішної збірки і перевірки архіву. Якщо змінився оригінал або контекст, локальний вибір більше не підставляється без повторного вибору.

Деталі встановлення: [QUEST_LOCAL_TEST_BUILD.md](QUEST_LOCAL_TEST_BUILD.md).

## Gossip
