# Provenance and content boundaries

The Ukrainian diagnostic paragraph in `addons/SpokenCommunity_ukrainian-diagnostic/Lore.lua` was originally authored for this task. Its examples test Unicode characters and punctuation; they are not translations of ClassicUA, Blizzard or Spoken prose. `Elwynn Forest` and map `1429` identify the existing target map. No game lore, artwork, fonts, sound files or source translation tables are bundled.

Spoken is an external dependency. Tests read unmodified code from commit `3c896874e27ec9e07d51a3578c0b9fa8545c9ac7` through local `git show`; no upstream implementation is vendored or included in the archive. Spoken's own code is MIT, copyright (c) 2026 Rusty Key, with third-party content exclusions documented by its LICENSE and THIRD_PARTY.md. See the pinned links in the preserved Stage 0 legal register.

The four Stage 0 documents are preserved from the local planning task. They are historical analysis, not proof of a current ClassicUA permission grant. ClassicUA code, translations and assets were not acquired or imported for Stage 1. No rights to those materials, future audio derivatives or third-party lore are granted by this local project. Resolve those permissions separately before any later import or release.

This project and its diagnostic artifact are local task deliverables; no public release or content licensing decision has been made.
